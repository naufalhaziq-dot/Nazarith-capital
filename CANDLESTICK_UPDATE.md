# Candlestick chart update

The SMC Academy and Entry Model Library candlestick illustrations now use distinct deterministic synthetic OHLC price-action profiles (market structure, liquidity sweep, FVG displacement/retracement, order-block retest, premium/discount range, and multi-timeframe trend).

Each chart includes proportional candle bodies and wicks, price grid/scale, time labels, and lesson-specific SMC overlays. The charts are educational simulations, not live or historical market data.

No Supabase integration was added. Existing standalone/local-storage architecture is retained.
